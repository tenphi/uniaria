The first release: framework-agnostic headless behavior for Button,
ToggleButton, Field, TextField, NumberField, Checkbox, CheckboxGroup,
Switch, Radio, RadioGroup, Dialog, Popover, Tooltip, Listbox, Select and
Combobox, with a React adapter, light-DOM custom elements, and the
conformance suites and testing tools both adapters pass.
