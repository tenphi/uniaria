# Button: Sous against React Aria

Generated by `pnpm bench` on 2026-10-15.

- Apple M1 Max, darwin 27.0.0
- Headless Chromium 153.0.8010.12
- React 19.3.0, react-aria 3.52.1
- Production builds; medians of 7 runs, each on a fresh page with 1000 buttons

Lower is better. Main-thread time is DevTools' `TaskDuration`: it includes
the browser's own input handling and style work, so the plain button is the
floor.
