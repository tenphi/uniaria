# Autocomplete spec

Status: approved by @tenphi on 2026-10-24

Autocomplete, a text input that filters a list and moves a highlight
through it while focus stays in the input, is specified in the composition
spec: [Autocomplete](../composition.md#autocomplete). Combobox is built on
it in popup mode ([Combobox](../composition.md#combobox)); the element,
`<uni-autocomplete>`, runs it inline.
