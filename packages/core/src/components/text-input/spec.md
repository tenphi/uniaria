# TextInput spec

Status: approved by @tenphi on 2026-10-24

TextInput, a native `<input>` or `<textarea>` with TextField's value
handling and no labelling, is specified in the composition spec:
[TextInput](../composition.md#textinput). TextField and NumberField compose
it ([The components rebuilt on them](../composition.md#the-components-rebuilt-on-them)),
and so does Autocomplete; it has no custom element.
